# 输入记录与连携图像识别

两项服务各自运行，独立于 Npcap 和伤害分析。首页显示状态并启停输入记录；连携在悬浮窗页启用。
先在设置中选择 `Endfield.exe`，目标按进程路径识别。

## 输入采集

「启动时记录输入」默认关闭。首页手动启停与启动选项分别保存。
普通权限 GUI 启动录制时，仅记录子进程申请管理员授权；取消授权显示失败，已具备权限时直接运行。

| 后端 | 记录内容与精度 |
| --- | --- |
| Windows Raw Input | 键鼠设备身份、原始键码、位移、按键及滚轮 |
| SDL3 | 手柄原始控制量、设备身份及映射关联 |
| `windows_hook` | Raw Input 缺失时的兼容事件；设备身份为空，鼠标移动为屏幕绝对坐标 |
| `windows_state` | 事件后端均未送达时的 8ms 前台状态采样；记录实际采样时间和精度。适用于按键状态，重复、滚轮、原始位移及短点击需事件后端 |

仅写入游戏前台输入。切出、断开设备、停止或换文件时写中断；再次进入保存按住状态基线。
原始报告优先，兼容路径去重后发布；文件保留后端切换诊断。

线程和通信分工：

- Windows 消息线程接收报告和事件；录制控制循环处理前台识别及状态采样。
- 独立写线程批量落盘，繁忙时每 250ms 刷新；有界队列溢出记录缺失区间。
- 状态 JSON 与 stderr 分别持续读取；错误缓存保留末尾 8KiB，异常退出时展示末尾诊断。
- 普通权限中继先创建日志目录，以单次随机凭据认证本机命名管道，传递状态、trace 轮换和停止命令。
- 事件由录制器直接写盘；控制连接断开后关闭文件并结束进程。
- 中继连接等待上限 30 秒；退出时请求停止并等待最多 5 秒，超时通过启动时持有的进程句柄终止并确认退出。

首页显示键盘、鼠标及缺失计数。每 5 秒写入 `input_backend_health`，包含消息线程推进、采样、原始报告和前台过滤计数。
采集故障单独显示在输入服务状态中。

## 文件与历史绑定

文件统一位于日志根目录的 `YYYYMMDD` 子目录：

| 情况 | 文件名 |
| --- | --- |
| 抓包写入 trace | 同名 `trace_*.input.jsonl` |
| 同一 trace 中重开录制 | `.part-时间.input.jsonl` |
| 独立录制 | `input_日期.input.jsonl` |

JSONL 包含版本、系统/单调时钟、序号、设备、焦点、中断和结束记录；结束时可用 trace 前缀 SHA-256 核对关联。
开始抓包或 trace 换文件时同步切换录制文件。输入文件仅供本地分析，Git 与便携打包均排除。

战斗分析自动发现同名文件，也支持每场「绑定 input log」。绑定保存相对 trace 的路径、对齐和槽位设置；「显示输入」独立控制绘制。
请选择覆盖本场战斗的文件。手动绑定保持所选文件，录制轮换后可重新选择；后台按需索引，重绘复用缓存。

- 对齐：毫秒级系统时间映射到战斗的 `0..duration_ms`，跨边界按住区间裁切显示；悬停保留原始起止。
- 日期不明：允许手动指定起点和偏移；位置保持系统时间语义。
- 解释：支持组合键、槽位和短/长按阈值，默认 280ms 为参考值；具体组合优先，每次按住解释一次，各设备单独匹配。
- 角色：战技/终结技按当时 LOADOUT 槽位归属，缺证据显示槽位；连携保持全局。
- 标记：蓝实线战技、橙实线终结技、紫虚线连携；同色区间表示按住，中断使用虚线边界。

绑定栏显示本场原始输入和解释动作数量，空范围时提示检查录制及对齐。其他输入和模拟量可按需显示。
输入是操作意图证据，技能释放、伤害和贡献仍采用 trace 解析结果。trace 重命名事务同步配套文件及绑定；列表移除仅移除引用。

## 连携识别

多个连携浮窗共用一套捕获和识别。隐藏期间继续运行，最后一个订阅者停用后释放资源。
取帧链路为 `QWindowCapture → QMediaCaptureSession → QVideoSink`，使用 FFmpeg / `uwp`（WGC）。

「连携识别设置」支持选目标、预览与校准。游戏重开后重新发现 HWND；布局自动匹配键鼠、手柄及组合键模式。
坐标基于客户区和黑边后的画面；非 16:9 同时核对等比缩放与左下锚定候选。预览开启时才转换整帧。

| 观测 | 更新规则 |
| --- | --- |
| 成功识别当前状态 | 立即更新该槽；明确亮前缀/暗后缀作为冷却证据 |
| 冷却条形状或明暗不明确 | 延续上次可信状态 |
| 有可靠填充速度 | 按近期速度估计剩余秒数；不可读时延续估算，到零保持就绪 |
| 速度不足、停滞或跳变 | 清除秒数估计，保留可信进度 |
| 新目标、布局或画面尺寸 | 重新确认；新布局至少需要三槽支持 |
| 低血量或染色 HUD | 分槽判断，阵亡需额外证据 |

已确认布局可分槽更新；CD 就绪整行变绿。无抓包时显示位置 1–4，当前队伍事件按槽位补充姓名和头像。
抓包停止或会话/目标变化时清除身份，视觉状态继续维护。

最高 20Hz，工作线程仅保留最新帧和结果。常规处理复制小区域，Qt 后端仍有整帧纹理复制成本。
无目标或画面持续无效时降低检查频率；相同展示状态复用，每 10 秒记录识别诊断。

模板支持四圆图标/四行进度条，切换样式时重测窗口。进度条宽度独立拉伸，高度决定文字、头像和条高比例。
进程内 `combo_snapshot` schema 2 携带 stream/sequence、画面有效性、四槽状态、观测进度和可空估计值，前端直接展示。

## 环境与验证

`Setup-Dev.cmd` 或 `prepare_native.py` 按清单准备 SDL3，后者支持 `--archive` 离线 ZIP。
便携包携带 SDL3、QtMultimedia、FFmpeg 插件及依赖闭包；缺少组件时显示对应服务故障。

测试入口为 `python -B _development/run_tests.py app-independent`，覆盖输入解释、队列、状态机、GUI 和自有窗口 WGC 链路。
实体 Xbox/DualSense、有线/无线/独占连接及实战识别率需分别实机验收。代码入口见 [源码导航](../../_internal/src/README.md)。
