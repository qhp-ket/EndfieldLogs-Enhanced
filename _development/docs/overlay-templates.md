# 原生浮窗皮肤

浮窗页可导入本地 JSON 原生皮肤，使用 `schema_version: 2`。不支持 HTML、URL、JS、执行表达式或浏览器后端。内置声明见 `_internal/dotnet/Runtime/Overlays/Skins/`，解析和校验位于同目录父级。

皮肤声明名称、默认窗口尺寸、设置、模块、布局及主题。模块仅支持 `damage`、`combo_skill`、`uid_mask`；布局支持单模块、横向排列和纵向排列。主题包含字体、配色、背景、边框、圆角、间距与本地图片，模块设置决定列、头像、形状和显示模式。以当前内置 JSON 为完整格式参考。

每个浮窗实例独立保存设置、顺序、位置、尺寸、字号、透明度、锁定、穿透及桌面显隐；关闭后隐藏，重置恢复皮肤默认布局。终末地风格由原生绘制实现，深浅色模式均可使用。

数据订阅由模块注册表汇总：伤害只使用简报，连携使用视觉快照，遮挡无需订阅。绘制模块不执行解析、识别或 rDPS 计算。独立浮窗使用 Python／浏览器无关的本机 WebSocket 客户端，GUI 内走现有快照队列。

背景图片保持静态绘制，WebP 动画只取首帧。导入只读取本地声明和图片，不修改用户原始模板文件。
