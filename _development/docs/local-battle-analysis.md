# 本地战斗分析

顶部「界面风格」切换原生 Qt 与仿官网本地网页，两者共享 canonical snapshot 和已加载报告。

## 时间轴与详情

- 按角色分组、技能类型分轨，重叠块可展开；显示重击及技能。
- 技能起止采用日志生命周期，伤害点单独标记。固定时长回退默认关闭，开启后以命中锚点补齐缺失起止。
- 可调时间范围、图形比例、秒/30F 单位；角色列、类型/BUFF 列支持拖动，右上角显示鼠标时间。
- 全队技力、主控切换单独分轨；技力和失衡区分观测、推算及未知值。
- BUFF 按状态合并，更新层数与结束时间，蓝点表示层数变化。
- 详情默认收起；顶部按钮、分隔线、最大化/还原及 × 同步状态。

技能构成按核心单次施放统计 DMG，详情读取核心贡献分配。
敌方数据分别展示实体抗性、本击有效抗性和失衡观测。
浮窗来源由历史选择和「返回实时日志」控制。

## 字体与头像

GUI 字号在设置中调整；角色名、技能类型及 BUFF 使用各自基础字号。
「显示角色头像」与「头像大小」在两种界面间共享保存，范围 50%–300%，默认 100%。

| 位置 | 基准直径 | 缩放因子 |
| --- | ---: | --- |
| 角色概览 | 32px | GUI 字号 × 头像比例 |
| 时间轴 | 40px | GUI 字号 × 头像比例 × 图形比例，受可见单元格限制 |

时间轴每名角色显示一次头像。源 PNG 分辨率为 128×128，显示大小由上表计算。
默认比例在 `gui/config.py: character_avatar_percent`；Qt 基准分别为 `detail.py: SKILL_AVATAR_PIXELS`、`timeline/labels.py: ROLE_AVATAR_PIXELS`。
网页入口为 `assets/shared.js: A.avatar` 及 `assets/timeline.js`。

控件路径见 [组件位置](battle-analysis-components.md)。名称优先显示词典，缺项回退核心名称或原 ID。
