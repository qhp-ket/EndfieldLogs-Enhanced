# 本地战斗分析

Qt 原生界面读取 canonical snapshot 和已加载报告。「显示设置」集中管理头像、伤害曲线和固定起止回退。

## 时间轴与详情

- 默认每个角色战技独立一轨，连携与终结共用一轨，「其他」轨道默认隐藏。角色名称格的齿轮可添加、排序轨道，勾选本场实际出现的技能块；自定义配置中未分配和后续新增的技能进入「其他」。配置按角色保存在便携设置中，空轨道自动隐藏，重叠块可独立展开。
- 技能起止采用日志生命周期，伤害点单独标记。固定时长回退默认关闭，开启后以命中锚点补齐缺失起止。
- 可调时间范围、图形比例、秒/30F 单位；角色列、类型/BUFF 列支持拖动，右上角显示鼠标时间。
- 全队技力、主控切换单独分轨；技力和失衡区分观测、推算及未知值。
- 原生伤害曲线默认累计 rDMG，支持切换 DMG、DPS、rDPS；DPS 按桶终点累计秒数计算，rD 缺失份额标为未知。鼠标参考线共用战斗时间。
- BUFF 按状态合并，更新层数与结束时间，蓝点表示层数变化。
- 详情默认收起；顶部按钮、分隔线、最大化/还原及 × 同步状态。

技能构成按核心单次施放统计 DMG，详情读取核心贡献分配。
敌方数据分别展示实体抗性、本击有效抗性和失衡观测。
「显示设置 → 角色统计与快照质量」按需展示角色 DMG、rDMG、DPS、rDPS、暴击率及完整快照质量字段。
表格支持数值排序、完整内容悬停及拖动列宽；列宽保存在便携设置中。输入文件绑定与解释选项位于「输入」，「显示输入」独立切换。
浮窗来源由历史选择和「返回实时日志」控制。

## 字体与头像

GUI 字号在设置中调整；角色名、技能类型及 BUFF 使用各自基础字号。
「显示角色头像」与「头像大小」保存到便携配置，范围 50%–300%，默认 100%。

| 位置 | 基准直径 | 缩放因子 |
| --- | ---: | --- |
| 角色概览 | 32px | GUI 字号 × 头像比例 |
| 时间轴 | 40px | GUI 字号 × 头像比例 × 图形比例，受可见单元格限制 |

时间轴每名角色显示一次头像。源 PNG 分辨率为 128×128，显示大小由上表计算。
默认比例在 `settings/model.py: character_avatar_percent`；Qt 基准分别为 `pages.py: SKILL_AVATAR_PIXELS`、`timeline/labels.py: ROLE_AVATAR_PIXELS`。

控件路径见 [组件位置](battle-analysis-components.md)。名称优先显示词典，缺项回退核心名称或原 ID。
