# C#／WPF 本体

Python／Qt 工作树为 `main/`（`main/python-qt`），C#／WPF 工作树为 `migration/`（`migration/csharp-wpf`）。C# 本体已接通抓包、录制、实时与历史分析、三类浮窗和本地官网上传兼容链路。当前交付为 `0.2.1-csharp.1` 的 r15 验收候选，尚未正式发布；实际游戏、OBS、实体输入及部分资源指标仍须验收。

新配置默认记录 JSONL，已有配置中显式的 `legacy`／`jsonl` 选择继续有效。界面保留可收起的左侧导航，支持深浅色和全局字号；便携包根 EXE 直接启动，应用、私有 .NET／WPF、原生组件、数据、源码和许可分类存放。使用方式见[根 README](../../README.md)，目录及独立重建见[打包说明](portable-packaging.md)。

## 工程与依赖

[解决方案](../../_internal/dotnet/EndfieldLogs.slnx)使用 .NET SDK 10.0.403，目标 Windows x64，运行库为 10.0.14。NuGet 版本和内容哈希由各项目的 `packages.lock.json` 固定，恢复使用 `--locked-mode`。本体不依赖 Python、Qt、浏览器或系统预装 .NET；Python 只用于开发工具及独立参考对照。

| 工程 | 职责 |
| --- | --- |
| Core | 摄取、证据、计时、归因、质量和报告 |
| Protocol | 固定描述符、生成消息与消息目录 |
| Native／Capture | Npcap、Win32、TCP、解密、分帧与采集会话 |
| Runtime | 录制、配置、历史、快照发布、独立服务与访问控制 |
| Desktop | WPF 主界面、战斗分析、Direct2D／DirectWrite 浮窗 |
| Specs／Tools | 契约、固定差分、合成回放和发行验证 |

协议按固定 Python 描述符的有效消息闭包生成，来源及缺口记录在 `Protocol/Schema/`。基线缺少的 `SC_ATTACH_SERVER_SKILL`、`SC_DETACH_SERVER_SKILL`、`SC_MERGE_MSG`、`SC_UPDATE_SERVER_SKILL` 不伪造实现。资源从已审核的清单恢复；统一 RSA 运行资源只随包交付，不入 Git、不写入诊断正文。官网 uploader 单独从校验过的官方 ZIP 提取，本体不构建或修改它。

## 数据与兼容边界

[JSONL 协议](trace-jsonl.md)保留字段存在性、事件顺序、宽整数身份、原始精度、非有限数值及业务证据。Python 和 C# 各自生产、读取并直接消费结构化事件，实时和详细分析不先还原文本。旧日志继续可读；独立导出器恢复官网兼容正文。连续分卷保留分析上下文，各卷签名变化使历史缓存失效，输入侧录按关联发现和校验。

| 边界 | 实现与验证范围 |
| --- | --- |
| 采集与归档 | 有序解码、合成加密采集、日志哈希、分卷及异常传播；写 trace 失败停止采集，避免发布未归档证据 |
| JSONL 与旧格式 | 角色／队伍、属性、装备、技能、HP、BUFF、动态黑板、笔意、技力、失衡、实体、计时和结算；固定旧场景逐事件、完整／摘要、分卷及双向读取 |
| 官网兼容 | 固定混合正文逐字节一致，官方 parser／uploader 本地读取、完整性证明、载荷和原文文档一致；不执行网络上传 |
| 计算 | 静态基线、动态来源、效果审批／叠层、逐击反事实分配、独立笔意账本、质量与贡献守恒的固定差分 |
| 历史 | 范围读取、按需分析、取消与来源修订、重命名、移出列表、输入关联及搬目录 |
| 配置 | 同目录原子写入、有效备份、损坏文件留档失败后继续恢复、旧路径迁移及显式格式选择 |
| 发布 | generation／revision／消费水位拒绝过期结果，reset 先于新数据；无完整分析订阅时不计算完整报告 |

默认值专项位于本地 `dotnet/jsonl-default-20261104/`，覆盖两版配置、实际合成加密采集入口、实时／历史、分卷、输入关联和固定正文导出。实际登录、游戏消息组合及原始游戏 DLL 的运行列入用户验收。BUFF 解析、腐蚀处理和分析轨道继续维护；被移除的只有网页后端及 BUFF／最近输入专用浮窗。

## 原生界面与后台服务

主界面依次为首页、悬浮窗、战斗日志、运行日志和设置。首页独立控制抓包、输入和连携识别；列表不提前计算完整报告。后台任务退出、批量加载、多选、导航收起、窄窗、大字号及深浅主题由产品控件检查覆盖。

战斗分析保留时间轴、累计 rDMG 伤害曲线、技能构成、敌方数据、技力／主控、失衡、抗性、BUFF 和输入轨道，以及事件概况、贡献分配、逐击和原始证据详情。角色自定义合轨中未分配的技能进入「其他」；连携输入只跨角色轨道。详情按需构建、默认收起，轨道按可见范围绘制，参考线独立更新；未知值和观测值不转换成推定百分比。

三类浮窗使用原生窗口和直接 Direct2D／DirectWrite 绘制，不经过整窗位图导出。保留 v2 JSON 组合皮肤、本地图片、列／排序、字体和头像比例、透明度、锁定、穿透、显隐及关闭后隐藏。隐藏桌面显示时窗口保留，供 WGC 捕获；全部停用或删除后释放共享绘图工厂。头像纹理和文字缓存有界，配置变化及目标重建时清理，不使用固定动画循环或强制 GC。

输入记录使用独立 worker、认证管道及有界队列；磁盘与消息线程分离，丢失区间明确记载。切换 trace 写入分片，结束保存 trace 前缀证明。管理员授权只用于记录子进程。视觉识别直接读取 WGC 帧区域，保留黑边映射、四槽确认、空位／阵亡／未知、临时校准与取消恢复；目标变化和隐藏预览清理旧帧。

本机 WebSocket 保留独立原生浮窗用途，仅监听 IPv4 loopback；有 Origin 的连接校验令牌，慢客户端使用有界发送。主界面浮窗经观察者队列接收快照，不依赖浏览器。

## 当前性能与资源

各结果只适用于对应输入和测量终点，不叠加不同轮次的收益。三组配对串行交替、新进程运行，计时不混入 profiler、构建或强制 GC。未变化的完整报告和绘图实现按源码相关性复用既有结果，不因程序集重建便把旧结论全部作废或外推。

2026-11-05 的独立引擎配对使用相同固定 JSONL、资源及逐批简报参考：

| 负载／指标 | Python／Qt | 当前 C# |
| --- | ---: | ---: |
| 720 击累计更新 CPU | 1.56 秒 | 0.53 秒 |
| 720 击更新 p95 | 620 ms | 214 ms |
| 7,200 击累计更新 CPU | 13.19 秒 | 2.98 秒 |
| 7,200 击更新 p95 | 3,149 ms | 371 ms |
| 7,200 击峰值 RSS／private | 491／478 MiB | 310／266 MiB |

逐批简报精确相同，trace 重放为零。证据为本地 `dotnet/live-current-paired-20261105/`；不包含 UI、抓包、录制或物理显示，批处理耗时不是游戏中的显示延迟。

摘要准备复用稳定、不可变的 BUFF 记录注释；modifier 变化逐记录失效，有动态／刷新／失衡事件时保留完整绑定路径，公开可写报告及 reset 隔离不变。同一 384 事件后缀追加到长历史后，修改前后 CPU 中位数 1.89→1.25 秒、分配 319→259 MB。正常时间戳输入末 30 秒的三轮对照中，CPU 6.33→4.66 秒、RSS 397→338 MiB、发布源龄 p95 96→69 ms，最终追平、未订阅完整流计算为零。证据为 `dotnet/stable-summary-sources-20261105/`。这组是 C# 自身对照，不替代 Qt 整机对照；仍有随历史增长的扫描，不宣称严格常数复杂度。

历史列表当前配对使用 400 条合成记录、200 次定位、175% DPI、相同字体和每屏七行；20 个停靠点的文字、顺序、裁切及尺寸一致。Qt／C# 滚动处理 p95 为 4.30／3.18 ms，峰值 RSS 235／156 MiB。终点为 UI 线程滚动处理及排队绘制，未测物理呈现；受控布局的初次绑定不纳入比较。证据为 `dotnet/history-current-paired-20261104/paired/`。

既有长完整报告、时间轴交互及组合客户端对照按相关源码复用；纯浮窗同帧负载的 CPU 和共同 WGC 观测延迟已有优势。**纯浮窗私有内存仍未达标**：同轮 Qt／硬件 D2D 约 78／116 MiB，容差为基线加 `max(5%,16MiB)`。当前三轮分阶段诊断中，首次空硬件／软件目标分别增加约 57.0／5.2 MiB private，硬件阶段托管对象仅增加约 48 KiB；这是初始化诊断，不是三浮窗稳定态对照。不能据此全部归因显卡驱动，也不以删内容、降更新量或高 CPU 软件路径换取单项过线。

**WGC 重启资源门槛仍未通过。** 当前合成窗口捕获、resize、lease、四槽识别、200 次连续更新及关闭清帧通过；36 次重建后句柄净增 91。帧／Surface／帧池／session／设备所有权已检查。独立原生捕获项程序三轮空循环均无增长，每轮创建／释放 30 项则均增加 30 个 ALPC 句柄，原生 `Release()` 返回 0；没有创建帧池、启动捕获或强制 GC。环境加载 NVIDIA 捕获模块，该事实不足以归因驱动，须在关闭第三方注入或另一环境中对照；程序不自行更改系统或第三方设置。当前诊断与输入保护后的复现源码见本地 `dotnet/automation-resources-20261105/`。

## 验证与交付边界

命令和范围见[测试说明](../tests/README.md)。统一入口默认构建当前源码、运行全部契约组及固定差分；`-Suite`／`-Group` 可选范围，`-SkipBuild` 必须有当前源码和产物的有效回执，不修改 golden 迁就实现。

```powershell
& _internal/dotnet/Verify.ps1
& _internal/dotnet/Verify.ps1 -Suite live-engine,live-allocation -Group live-engine,live-allocation
python -B -m unittest discover -s _development/tests/resources -p "test_*.py"
```

`--check-navigation`、`--check-pages` 不创建桌面窗口。`--check-product-startup <输出.json>` 从真实产品入口创建主窗口及服务，检查导航、主题、字号、配置与退出；隔离配置禁用抓包、输入、浮窗、更新请求和全局快捷键，窗口不激活、不接收输入。包根 EXE 在全新中文／空格路径和搬目录后分别执行该入口，并核对实际 CoreCLR／WPF 路径。`--check-overlay-lifetime` 检查停用释放和关闭隐藏语义。

窗口检查通过控件／Dispatcher 操作，不注入全局键鼠、不激活窗口；有界性能负载串行运行。自有窗口 WGC 检查不能代替真实游戏、OBS、物理屏幕和实体输入。

交付前验证 ZIP CRC、相对路径／大小／SHA-256 清单、上一候选差异、私有运行库缺失时拒绝全局回退，以及 SOURCE 在无 Git 目录中的独立重建。`source_dirty` 如实表示包含未提交源码，不表示损坏；验收候选不自动提交、推送或发布。

用户实测聚焦实际登录／抓包、JSONL 录制及输入绑定、OBS 桌面隐藏捕获、管理员输入／手柄、混合 DPI 和外部捕获环境隔离。未达标项与待实测项保留，不能用测试数量或自动化启动通过替代全部发行条件。
