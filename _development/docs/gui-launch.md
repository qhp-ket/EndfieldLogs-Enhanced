# GUI 启动与排查

双击根目录 `Start-GUI.cmd`。CMD 显示「正在打开 GUI，请稍候…」，GUI 出现后退出。
便携包使用随包环境，源码环境先执行 [Setup-Dev](development-environment.md)。

```powershell
.\Start-GUI.cmd --check
.\Start-GUI.cmd --game-dir "D:\Games\Endfield Game"
.\Start-GUI.cmd --ws-port 29326
```

`--check` 同步检查依赖及启动条件。初始化失败时弹窗、写日志并在 CMD 保留错误。
GUI 启动握手最多等待 60 秒；超时提示进程 PID 和日志路径，保留子进程供继续初始化或排查。
调试入口 `python launch_gui.py` 保留控制台。
解释器依次选择 `ENDFIELD_GUI_PYTHON` → 包内 Python → 初始化记录 → `.venv` → `py -3` → PATH。

## 抓包与设置

首页「启动抓包」手动开始，设置中的「启动时开始抓包」默认关闭。
准备 [Npcap](https://npcap.com/#download) 和游戏安装，关闭其他抓包客户端；缺项时首页显示原因，历史分析仍可用。

| 后台状态 | 按钮 |
| --- | --- |
| 停止／失败且清理完成 | 启动抓包 |
| 正在启动 | 正在启动…（禁用） |
| 运行，包括等待游戏或登录 | 停止抓包 |
| 正在停止 | 正在停止…（禁用） |

「设置 → 游戏路径」可重选 `Endfield.exe` 或含 `GameAssembly.dll` 的目录。
游戏路径和 WS 端口在下次抓包启动生效。**停止抓包后重新启动，需要重开游戏。**

连携在悬浮窗页启用，输入记录在首页独立启停。设置与诊断见 [独立服务](independent-services.md)。
「关于」支持正式版本检查、忽略版本和前往下载；启动后台检查失败时保持安静，手动检查显示错误原因。

## 显隐与资源

| 操作 | 范围 |
| --- | --- |
| 首页「隐藏到托盘」或 `Ctrl+Shift+O` | 隐藏/恢复主窗、分析和设置等 GUI；后台服务和浮窗继续运行 |
| 托盘点击、菜单或同一快捷键 | 恢复隐藏前的 GUI；托盘菜单提供退出程序 |
| `Ctrl+O` / 浮窗显隐按钮 | 仅控制浮窗 |
| 主窗口关闭 | 退出程序 |

快捷键可在设置修改；无系统托盘时使用任务栏最小化。
日志页面按需布局有界文本缓存。关闭分析窗口后释放完整报告和输入缓存，下次打开按需加载；隐藏期间保留窗口与 Qt 环境。

浮窗功能启停、桌面显隐、排序及尺寸见 [浮窗配置](overlay-templates.md)。
OBS 使用 Windows 10（WGC）窗口采集，隐藏期间可继续接收同一窗口画面。
本地伤害浮窗跟随历史选择；WS 始终提供实时数据。

「战斗日志」支持 Ctrl/Shift 多选与批量加载，浮窗显示最后选择；「返回实时日志」恢复实时。
记录以原文件引用保存，列表移除仅移除引用。分析功能见 [本地战斗分析](local-battle-analysis.md)。

## 日志与错误

「运行日志」收集 Python logging，保留最近 800 个文本块，提供复制、清空显示和打开目录。
磁盘日志独立保存；早期启动、直接输出和 native/子进程错误可从文件查看。

| 路径（相对根目录） | 内容 |
| --- | --- |
| `.dev-gui/settings.json` | GUI、游戏路径、端口、浮窗设置 |
| `.dev-gui/logs/launcher.log` | 启动错误与运行日志 |
| `.dev-gui/logs/launcher-stdio.log` | 直接输出及 native 错误 |
| `.dev-gui/logs/battles/` | 按日期归档的 trace、input log 和诊断 |

配置采用临时文件、同步落盘和原子替换，并保留上一份有效备份；损坏文件单独保留，读取时恢复备份或默认值。
包内路径随程序目录解析；游戏目录等外部选择保持原路径，历史引用和输入绑定随目录迁移。

官网上传选择 `trace_*.log`，保留 `.log.status.json`，并满足官网完整性校验。
上传器准备见 [运行资源](runtime-resources.md)。
