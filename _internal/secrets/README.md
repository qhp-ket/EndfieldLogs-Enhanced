# 本地密钥目录

私钥和本地敏感文件统一放在此目录；Git 只保留本文档，不提交实际文件。

`client_privkey.pem` 是抓包链路的运行资源。当前文件与干净官网发行包完全一致，
不是个人账号密钥。便携发行工具仅允许打包已核对 SHA-256 的这一份公共发行资源；
其他密钥、账号会话、配置、日志均不得进入发行包。

不要在 Python 源码、`.env` 或配置示例中内嵌真实密码、令牌或私钥。
若未来需要其他私钥，放在本目录并显式配置路径；不要扩大打包白名单。

源码克隆后请从可信的 ZMDLogs 完整发行包取得同名文件并放入此目录；
随机生成的 RSA 密钥不能替代游戏协议需要的密钥。来源、已验证哈希、独立 uploader
准备方法及需要先获取密钥的测试入口见 [运行资源说明](../../_development/docs/runtime-resources.md)。

没有此文件时仍可打开 GUI 和分析本地日志；只有实时采集与显式密钥集成测试需要它。
